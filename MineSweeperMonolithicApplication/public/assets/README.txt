Place audio assets in this folder.

Expected files used by Minesweeper:
- /assets/audio/reveal.wav  (short, soft click/pop for cell reveal)
- /assets/audio/flag.wav    (light pop/bounce for flag toggle)
- /assets/audio/win.wav     (subtle chime for win)
- /assets/audio/lose.wav    (soft thud/buzz for loss)

These should be small, royalty-free samples. You can replace them with your own as long as the file names remain the same or you update the src paths in Minesweeper.js.
